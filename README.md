# 🚀 N. Nijam Maideen — Developer Portfolio

A modern, ultra-responsive **Developer Portfolio Web Application** built with **HTML5, CSS3, JavaScript (ES6+)** and powered by **Vite**. Designed with premium **glassmorphism aesthetics**, dynamic **particle backgrounds**, and interactive **micro-animations** to create a stunning first impression.

---

## ✨ Live Features

| Feature | Description |
|---|---|
| 🎬 Preloader | Triple-ring animated spinner with gradient initials |
| 🌌 Particle System | Canvas-based constellation network background |
| ✨ Cursor Glow | Ambient radial glow that follows mouse movement |
| ⌨️ Typing Effect | Rotating developer phrases with typewriter animation |
| 🔢 Animated Counters | Numbers animate from 0 → target with cubic easing |
| 📜 Scroll Reveal | Sections slide-in using IntersectionObserver API |
| 🃏 3D Tilt Cards | Perspective-based hover effects with inner glow |
| 📊 Skill Bars | Gradient progress bars animate on scroll |
| 🌗 Dark/Light Theme | Smooth transitions with persistent localStorage |
| 📋 Resume Drawer | Slide-over resume view with Print/PDF export |
| 🔝 Back to Top | SVG scroll progress ring indicator |
| 📱 Fully Responsive | Mobile-first design across all breakpoints |

---

## 🛠️ Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, glassmorphism, grid, flexbox, animations
- **JavaScript (ES6+)** — DOM, Canvas API, IntersectionObserver, localStorage
- **Vite** — Lightning-fast module bundler
- **Google Fonts** — Outfit, Plus Jakarta Sans, JetBrains Mono
- **Font Awesome 6** — Icon library

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/nijam-portfolio.git
cd nijam-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
